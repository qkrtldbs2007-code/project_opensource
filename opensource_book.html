# 1. 현재 폴더를 Git 저장소로 초기화 git init # 2. 변경된 모든 파일을 스테이징 영역에 추가 git add . # 3. 첫 번째 버전 기록(커밋) 남기기 git commit -m "첫 HTML 사이트 업로드" # 4. 기본 브랜치 이름을 main으로 설정 git branch -M main # 5. 원격 저장소(GitHub) 연결 (본인 주소로 변경) git remote add origin https://github.com/사용자아이디/my-html-site.git # 6. GitHub로 코드 올리기 git push -u origin main # 1. 최신 main 내용 먼저 받기 git checkout main git pull origin main # 2. 새 브랜치 생성 및 이동 (예: feature/navbar) git checkout -b feature/navbar
